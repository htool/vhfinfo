# VHFinfo help

Map and Nearby help: [htool/VHFinfoSite HELP.md](https://github.com/htool/VHFinfoSite/blob/main/HELP.md)

This repository is the GeoJSON dataset and the SignalK plugin. The plugin
writes the nearest lock/bridge/marina and VTS to the SignalK path you
configure, and serves `/plugins/vhfinfo/nearby`.
